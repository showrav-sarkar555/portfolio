## 🚀 Key Features

- **Dynamic Hero Section:** Glowing gradient typography, interactive typewriter effect, and tech badge pills.
- **Glassmorphism UI:** Premium dark-mode aesthetics with subtle cyan neon borders, backdrop blurs, and micro-animations.
- **Interactive Project Showcase:** 6 featured projects spanning Web Development, Machine Learning, and UI/UX with real-time category filtering.
- **Interactive Contact & Toast Modals:** Functional client-side contact form with `mailto:` integration, Toast notification modal, and 1-click email/phone copy-to-clipboard buttons.
- **Three.js & Parallax Animations:** Animated profile orb, particle backgrounds, and smooth scroll effects.
- **Fully Responsive:** Carefully tested across mobile, tablet, and desktop viewports.

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/showrav-sarkar555/portfolio.git
   cd portfolio
   ```
2. **Open the site:**
   - Double-click `index.html` to launch in your browser, or
   - Use VS Code Live Server / `npm run dev` for live reloading.
